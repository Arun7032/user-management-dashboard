# User Management Dashboard

A React-based User Management Dashboard built using Vite.

## Features

- View Users
- Search Users
- Sort Users
- Filter Users
- Pagination
- Add User
- Edit User
- Delete User
- Responsive UI
- Form Validation
- Error Handling

---

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Fetch API
- Vitest
- React Testing Library

---

## Installation

Clone the repository

```bash
git clone <repository-url>
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

---

## Build

```bash
npm run build
```

---

## Preview

```bash
npm run preview
```

---

## Run Tests

```bash
npm test
```

## Assumptions

- JSONPlaceholder does not persist data.
- CRUD operations update local state after successful API requests.
- Department values are simulated because the API does not provide them.
